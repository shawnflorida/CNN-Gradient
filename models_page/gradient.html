Gradient Boosting

Gradient boosting is a machine learning technique that combines weak learners, such as decision trees, to form a strong learner. It works by iteratively adding new classifiers that focus on the cases that were misclassified in the previous round, thus improving the accuracy and performance of the model. Gradient boosting can be used to address the problem of class imbalance in sign language recognition, as it can assign different weights to different classes and minimize the loss function. Gradient boosting has been shown to have better accuracy and higher recognition efficiency than other techniques, such as CNN, GBDT, and XGBoost, for sign language recognition tasks.

Gradient boosting is a machine learning technique for building predictive models, particularly for regression and classification problems. It is an ensemble learning method, meaning it combines the predictions of multiple weak learners (typically decision trees) to create a strong predictive model.

The basic idea behind gradient boosting can be summarized as follows:

1. Weak Learners: Gradient boosting starts with a weak learner, often a shallow decision tree. This initial model is trained on the dataset, and its predictions are used as the first approximation.

2. Residuals: The difference between the actual values and the predictions made by the weak learner (residuals) is calculated. The goal is to improve upon these residuals in the next iteration.

3. Gradient Descent: In the subsequent iterations, new weak learners are added to the ensemble, and each one focuses on correcting the errors (residuals) made by the previous models. This is done by using gradient descent to minimize the loss function, which measures the difference between the predicted and actual values.

4. Weighted Sum: The predictions from all weak learners are combined into a weighted sum, where each learner's contribution is determined by its performance in reducing the overall error.

5. Boosting: The process is repeated for a predefined number of iterations or until a certain level of accuracy is achieved. Each new weak learner "boosts" the overall model's performance by addressing the mistakes of the previous learners.

How is Gradient Boosting used in this study?

Gradient Boosting is a machine learning algorithm used for classification problems in this study. It is applied to address the three types of class imbalances present in the Filipino Sign Language (FSL) dataset: class imbalance in the dataset, class imbalance during training, and class imbalance during testing. The study uses Gradient Boosting to combine weak learners, such as decision trees, to create a strong learner that can improve the accuracy and performance of FSL recognition. The study also compares the effectiveness of Gradient Boosting with other techniques, such as SMOTE and SVM,when paired with CNN for FSL recognition. The study uses various performance metrics, such as accuracy, F-1 score, recall, and precision, to evaluate the models' performances. The study also analyzes the time complexity and significant differences among the values of each FSL recognition using the three groups of algorithms (Gradient Boosting, SVM, and SMOTE).
