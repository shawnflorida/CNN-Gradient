Synthetic Minority Over-sampling Technique: Background

SMOTE, which stands for Synthetic Minority Over-sampling Technique, is an algorithm used in the field of machine learning and data mining to address the class imbalance problem. Class imbalance occurs when one class in a classification problem has significantly fewer instances than the other class or classes. This can lead to biased models that perform poorly on the minority class.

SMOTE was introduced to address this issue by oversampling the minority class, creating synthetic examples rather than simply duplicating existing ones. The algorithm works as follows:

  1. Selection of a Minority Instance: SMOTE randomly selects an instance from the minority class.
  2. Selection of k Nearest Neighbors: It then identifies k nearest neighbors for the selected instance. The value of k is a parameter specified by the user.
  3. Generation of Synthetic Instances: SMOTE creates synthetic instances by interpolating between the selected instance and its k nearest neighbors. This is done by choosing random values for each attribute and creating a new instance.
  4. Repeat: Steps 1-3 are repeated until the desired balance between the minority and majority classes is achieved.

SMOTE as approach to Class Imbalance

SMOTE (Synthetic Minority Over-sampling Technique) is a technique commonly used in the context of imbalanced datasets in machine learning. However, its application in image processing training might not be as straightforward as in tabular data. SMOTE is typically used with feature vectors, and applying it directly to image data might not yield meaningful results.

In image processing, particularly for training deep learning models such as Convolutional Neural Networks (CNNs), there are other techniques and considerations to address class imbalance:

  1. Data Augmentation: Instead of generating synthetic samples, data augmentation involves applying various transformations to the existing images, such as rotation, flipping, scaling, and changes in brightness or contrast. This can effectively increase the size of your training dataset and improve model generalization.
  2. Weighted Loss Functions: Modify the loss function to assign different weights to different classes. This way, the model pays more attention to the minority class during training.
  3. Transfer Learning: If you have a pre-trained model on a large dataset, you can fine-tune it on your imbalanced dataset. This leverages the knowledge gained from the larger dataset and adapts it to your specific problem.
  4. Ensemble Methods: Train multiple models and combine their predictions. This can be particularly useful when dealing with imbalanced datasets.
  5. Use Pre-trained Models: Utilize pre-trained models like those available in deep learning frameworks. Fine-tune these models on your dataset to leverage their learned features.

Takeaway

With SMOTE as an approach to class imbalance in image recognition is not the ideal solution to train well with a very limited dataset. Having only 55% accuracy, low precision and recall will result to bad predictive model. The sensible reason behind this poor performance is because produced instances are located mostly within noisy and overlapping areas, not to mention that the synthetic instances are unrealistic which is sensitive especially that we are dealing with sign language prediction.
